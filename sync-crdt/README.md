# sync-crdt

Local-first CRDT-ядро с **файберной реактивностью** в классической TS-экосистеме.
Портируются идеи [giper/baza](https://github.com/giper-dev/baza) и рантайм-модель
[$mol_wire](https://github.com/hyoo-ru/mam_mol/tree/master/wire), но без MAM,
без глобального namespace, без `.view.tree` и без кодогенерации.

> **Статус: проектирование.** Кода пока нет — в репозитории только планы.
> Референс-клоны лежат рядом и не коммитятся: `../baza`, `../mol`.

---

## Что это будет

Пакет `@sync/core` — движок, в котором:

- данные живут локально и сходятся между узлами без сервера-арбитра (CRDT);
- чтение остаётся **синхронным**, даже если под ним IndexedDB, расшифровка и
  проверка подписи — за счёт файберов и Suspense-протокола;
- один бинарный формат работает одновременно как сетевое сообщение, формат на
  диске и файл дампа;
- ядро не знает про Vue, React и DOM — фреймворковые биндинги отдельными пакетами.

Первый потребитель — [vue-sync-engine](../vue-sync-engine): его query-слой
переезжает поверх этого ядра, а `Mirror`/`mutationQueue`/патч-протокол исчезают.

## Ключевые решения одной страницей

1. **Отдельное ядро, а не правка vue-sync-engine.** Тот — server-authoritative
   fetch-кэш, это — local-first CRDT. Разные модели данных, общий потребитель.
2. **Файберы переносим.** Это не $mol-специфичная магия, а чистый JS: Suspense
   через `throw Promise` + позиционное переиспользование одноразовых задач.
   Именно они позволяют писать `pawn.title()` вместо `await pawn.title()`.
3. **Субстрат — `alien-signals/system`**, а не `alien-signals` целиком.
   Нужен граф с `link/unlink/propagate/checkDirty`, а свой `update()` мы пишем
   сами: штатный `computed()` некорректно ведёт себя при `throw` в геттере
   (подробности — [ADR-003](docs/00-decisions.md#adr-003)).
4. **Без декораторов.** `erasableSyntaxOnly` остаётся включённым; каналы
   создаются функциями `solo()` / `plex()`, а не `@mem`.
5. **Один бинарный формат** для провода, диска и дампа.
6. **Между вкладками ходят сырые паки**, а не патчи — CRDT делает патч-протокол
   ненужным.

## Термины

| Термин | Значение |
|---|---|
| **Unit** | Минимальный неделимый кусок состояния; иммутабельный вид над `ArrayBuffer` |
| **Sand / Gift / Seal / Pass** | Виды юнитов: данные / права+ключ / подпись / публичный ключ |
| **Land** | Единица синхронизации, прав и шифрования; контейнер юнитов |
| **Pawn** | Типизированный вид на `(land, head)`; не хранит данные |
| **Head / Self / Lead** | Родитель / собственный id / предыдущий сосед — рёбра графа |
| **Face** | Векторные часы ленда: `peer → { time, tick, summ }` |
| **Pack** | Бинарный контейнер: заголовок ленда + фейсы + юниты |
| **Fiber** | Узел реактивного графа, умеющий приостанавливаться на Promise |
| **Atom** | Долгоживущий файбер с кэшем (аналог `computed` + `signal`) |
| **Task** | Одноразовый файбер: побочный эффект, выполняемый ровно один раз |
| **Channel** | Функция вида `f()` — чтение, `f(v)` — запись |
