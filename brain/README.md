# brain

Second brain: одно local-first PWA, внутри — модули. Заметки, задачи, дневник
питания и всё, что добавится потом. Данные живут на устройстве и сходятся между
устройствами без сервера-арбитра — на [sync-crdt](../sync-crdt).

> **Статус: каркас, шесть модулей и доступ по passkey.** План и стадии —
> [docs/00-plan.md](docs/00-plan.md).

---

## Устройство

```
apps/web/            оболочка: роутер, реестр, «Сегодня», инбокс, палитра, доступ
packages/module-kit/ контракт BrainModule, чеканка лендов, сборка пространств
packages/ui/         токены оформления и компоненты на @robonen/primitives
packages/auth/       конверт DEK/KEK, passkey, фраза восстановления, замок
packages/std/        хелперы без домена и без UI: даты, числа
modules/notes/       заметки: список, теги, wikilinks, заметка дня
modules/tasks/       задачи: GTD-корзины, проекты, дедлайны, повторы
modules/kcal/        дневник питания: записи, каталог, нормы
modules/bookmarks/   ссылки на потом: статусы чтения, теги
modules/projects/    проекты: статус, период, стек, команда, оплаты, журнал
modules/trackers/    привычки, настроение, произвольные метрики
```

Как написать свой модуль — [docs/02-module-guide.md](docs/02-module-guide.md).
Доступ и шифрование — [docs/01-security.md](docs/01-security.md).

Направление зависимостей одно:
`apps/web → modules/* → module-kit → ui → std`. Модули друг про друга не знают;
единственная связь между ними — ссылки на сущности (`Link` адресует через
границы лендов) и контракт.

**Ленд на модуль.** Ленд — единица синхронизации, прав и шифрования, поэтому
граница лендов совпадает с границей модулей. Адрес ленда чеканится из имени
модуля детерминированно, и `kcal` даёт ровно тот адрес, с которым дневник уже
живёт: переезд данных — не переливка, а открытие того же ленда.

## Добавить модуль

1. `modules/<id>/` — пакет с `defineModule({ id, title, land, routes, … })`.
2. Имена моделей через `scoped('<id>')`: реестр `Models` один на приложение.
3. Строка в `apps/web/src/app/modules.ts`.

Регистрация статическая: «система иногда пополняется» решается пересборкой, а
не загрузкой плагинов в рантайме.

## Команды

```bash
pnpm dev         # оболочка на localhost:5173
pnpm build       # production-сборка
pnpm test        # весь workspace
pnpm typecheck   # tsc --noEmit по всем пакетам
pnpm lint        # eslint (--fix у lint:fix)
```

Пакеты `@sync/*` подключены симлинками из соседнего репозитория и должны быть
собраны там.
